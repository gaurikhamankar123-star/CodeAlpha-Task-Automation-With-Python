# Task 3 - File Automation with Python Scripts

## 📌 Project Description

This project automates the process of moving all `.jpg` image files from one folder to another using Python.

Instead of manually moving each image file, the Python script automatically identifies JPG files and moves them to the destination folder.

## 🛠️ Technologies Used

* Python
* os module
* shutil module
* File Handling
* Loops and Conditional Statements

## ⚙️ How It Works

1. The script reads all files from the source folder.
2. It checks whether each file has a `.jpg` extension.
3. JPG files are selected automatically.
4. The selected files are moved to the destination folder.
5. A message is displayed for every moved file.

## ▶️ How to Run

Run the following command in the terminal:

```bash
python move_jpg_files.py
```

## 🎯 Objective

The objective of this project is to demonstrate how Python can be used to automate repetitive file-management tasks.
